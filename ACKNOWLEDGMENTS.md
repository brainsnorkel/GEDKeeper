# Acknowledgments

GEDKeeper3m is a macOS-optimized build of [GEDKeeper](https://gedkeeper.net/),
the personal genealogical database editor.

## Original Authors

GEDKeeper was created and is maintained by **Sergey V. Zhdanovskih** and
contributors. The project has been actively developed since 2009 and represents

modifications noted in the commit history of this repository.

### Modifications in GEDKeeper3m

- macOS Dark Mode support via SystemColors integration
- Native San Francisco font rendering
- macOS Catalina (10.15+) compatibility
- Tab and theme rendering fixes for Eto.Forms on macOS
- Font disposal safety for shared NSFont instances
- System appearance change observation
- macOS app bundle configuration (Info.plist, GEDCOM file associations)
